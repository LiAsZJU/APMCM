# 亚太赛 APMCM 高分论文与试题

本目录仅收录 **APMCM 亚太地区大学生数学建模竞赛** 资料，与工作区中的美赛 **MCM/ICM** 资料分开存放。

当前收录的是组委会公开发布的 **2024年第十四届 APMCM 中文赛项优秀论文**。经官方获奖名单核对，6篇论文均为一等奖。

## 收录内容

| 题目 | 一等奖论文 | 试题与附件 |
|---|---|---|
| A题：飞行器外形的优化问题 | 队伍02838、队伍03112 | 原题PDF |
| B题：洪水灾害的数据分析与预测 | 队伍00536、队伍02462 | 原题PDF；`train.csv`、`test.csv`、`submit.csv` |
| C题：基于量子计算的物流配送问题 | 队伍00023、队伍02422 | 原题PDF；官方提供的6篇背景附件 |

其中，队伍02462为研究生组一等奖，其余5支队伍为本科组一等奖。

## 数据说明

B题三个CSV为官方原始文件，编码为 GB18030：

- `train.csv`：1,048,575条数据，22列。
- `test.csv`：745,305条数据，22列。
- `submit.csv`：745,305条提交模板记录，4列。

若软件打开后中文乱码，请以 GB18030/GBK 编码导入，不要直接覆盖原文件。

## 阅读建议

1. 先读原题并独立列出每问的输入、输出、约束和评价指标。
2. 同一题的两篇一等奖论文对照阅读，重点比较模型选择、验证方式和结果表达。
3. B题适合练习大规模数据处理与预测；A题适合学习机理与优化；C题适合学习QUBO建模和组合优化。

下载来源和文件核验结果见 `来源记录.tsv`；官方获奖名单保存在 `2024_APMCM_中文赛项/来源证明/`。
